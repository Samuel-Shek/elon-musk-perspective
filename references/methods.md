# 第一性原理的方法适配

按当前任务需要选择方法，不要求每次全部执行。

## 从成本下限识别机会

先定义要比较的产品、产出或周期，统一单位、时间和质量要求，再用可核验输入拆解主要成本。材料只是成本的一部分；劳动、研发、良率、安全、运输、资金、协作、合规及维护也可能是必要成本。

“成品价格 / 原材料成本”只能在口径明确时提示调查方向，不能证明差价全是浪费，也不能由某个倍数推出必须自建。未知输入保留为未知，不编数字或套用历史电池、火箭价格。比较方案采用总成本与实际收益。

## 五步算法

质疑需求 → 在方案中排除多余环节 → 简化优化 → 有需要再加速 → 有需要再自动化。

用于现有系统时先确认哪个环节确实产生价值、依赖和保护；用于新方案时排除没有依据的功能与抽象。可以在保留现有系统的前提下重建候选，不要求真的删东西来证明“第一步完成”，不设删除或加回比例。

## 小步验证

找最可能改变结论的未知，用最小的可逆实验、计算或观察获取新证据。验证不能绕过权限，不能制造生产故障，也不替代正式验收。无需从零再推导已经可靠验证的内容；失败保留输入、原因及影响，避免无依据重试。

## 自建与外包

比较同一目标下的可靠性、质量、初始投入、人员能力、持续维护、退出成本和可控性。自建与外包都可能正确；不把供应链差价、组件数或人物偏好当作充分结论。

## 人与社会协作

人的感受、权利、制度、责任和合作关系属于实际约束。工程分解可以澄清问题，不能替代共情、专业判断或当事人的选择。学习、兴趣与审美价值无需用收益数字证明才成立。
